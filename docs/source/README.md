# Исходники документации

Каждое руководство пишется здесь один раз, а потом собирается в несколько форматов.

| Исходник | Что из него получается |
|---|---|
| `install.js` | `docs/INSTALL.md` и `docs/Инструкция.docx`: развёртывание и работа |
| `scripts-guide.js` | `docs/SCRIPTS.md`, `docs/Скрипты.docx` и страница приложения `web/help/scripts.html`: скрипты для начинающих |

Текст записан списком блоков: `['h1', 'Заголовок']`, `['p', 'Абзац']`,
`['code', [строки], 'python']`, `['table', [заголовки], [строки], [ширины]]`,
`['img', 'файл.png', 'подпись']` и так далее. Внутри строк работают `**жирный**` и `` `код` ``.
Рисунки лежат в `docs/img`.

Правьте именно эти файлы. Готовые .md, .docx и страницу справки руками не трогайте: при
следующей сборке правки пропадут.

## Сборка

Нужны Node.js и Microsoft Word.

```powershell
cd docs\source
npm install docx@9.13.0          # один раз
node build.js                    # Markdown, Word и страница в приложении
powershell -ExecutionPolicy Bypass -File toc.ps1   # оглавления в Word
```

Для обновления только Markdown и встроенной HTML-справки по скриптам без Word и npm-пакетов:

```powershell
node docs/source/build.js --text-only --scripts-only
```

Файлы Word этот режим не обновляет. Для них нужна полная сборка выше.

Оглавление в Word может заполнить только сам Word, поэтому для него отдельный шаг. Номер
версии на титульном листе берётся из `app/__init__.py`.
