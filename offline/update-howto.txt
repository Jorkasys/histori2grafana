historian2grafana — обновление комплекта без Docker до версии {version}

Что в архиве
  historian2grafana-offline\   новые файлы программы (без Python, PostgreSQL и Grafana)
  Как обновить.txt             этот файл

При обновлении сохраняются: скопированные данные (папка data), настройки
подключения к историку, сохранённые скрипты и файл .env.


ШАГИ

1. Остановите приложение: закройте окно start.bat и запустите stop.bat
   из папки комплекта.

2. В папке комплекта (там, где лежит start.bat) удалите папки app и web.
   Папку data и файл .env НЕ трогайте.

3. Откройте этот архив и скопируйте СОДЕРЖИМОЕ папки historian2grafana-offline
   в папку комплекта. На вопрос Windows о совпадающих файлах выберите
   «Заменить файлы в папке назначения».

4. Запустите start.bat. Первая строка окна должна быть такой:
       historian2grafana {version} — запуск

5. Если браузер уже был открыт, обновите страницу с очисткой кэша: Ctrl+F5.
   Номер версии виден внизу каждой страницы приложения.

База данных дообновится сама при первом запуске. Копирование продолжится
с места остановки и догрузит из историка всё пропущенное.


ЕСЛИ ЧТО-ТО НЕ ТАК

- «порт ... занят»: приложение уже запущено в другом окне. Закройте его,
  запустите stop.bat, затем снова start.bat.
- Страница выглядит по-старому: обновите её с очисткой кэша, Ctrl+F5.
- В окне start.bat по-прежнему старая версия: вы скопировали папку целиком
  (получилось historian2grafana-offline\historian2grafana-offline). Нужно
  копировать её содержимое — повторите шаги 2–3.
- Нужно вернуться на прежнюю версию: повторите шаги с архивом прежней версии,
  данные не пострадают.

Что изменилось в версии — в файле CHANGES.md в папке комплекта.
