# Что нового

## 1.1.1 — октябрь 2026

- **Руководство по скриптам для начинающих** — для тех, кто не программировал: первый скрипт
  за две минуты, правила записи, готовые рецепты, справочник функций, разбор ошибок и
  шпаргалка. Открывается прямо из приложения (ссылка на странице «Скрипты»), а также лежит в
  `docs/SCRIPTS.md` и `docs/Скрипты.docx`.
- Понятные сообщения об ошибках в скриптах: дробное число через запятую (`60,5`), кавычки
  «ёлочки» и тире из Word, опечатка в названии функции или имени (с подсказкой похожего), имя
  тега без `tag("…")`, пропущенная запятая.
- Подписи шкалы графика с дробным шагом делений (2,5) больше не округляются до целых.
- Архив-обновление несёт файл «Как обновить.txt» с шагами установки.

Новых библиотек версия не требует; обновление — тем же архивом-обновлением.

## 1.1.0 — октябрь 2026

**Графики**

- Несколько тегов на одном графике: щелчок по тегу кладёт его на выделенный график, кнопка
  «Новый график» начинает следующий. «Все на один график» и «Каждый тег отдельно» раскладывают
  выбранное разом.
- У каждой единицы измерения своя шкала (слева и справа, цветом тега); теги с одной единицей
  делят одну шкалу.
- Масштаб по обеим осям: протянуть мышью влево-вправо — время (данные загружаются подробнее),
  вверх-вниз — значения, по диагонали — и то и другое. Двойной щелчок или «Вернуть прежний
  период» — назад. Ссылка «Шкала» — задать шкалу числами.
- Курсор общий для всех графиков страницы; в легенде — значение под курсором, щелчок по имени
  скрывает ряд.
- На длинных периодах вокруг линии — бледная полоса минимум–максимум: короткие выбросы видны и
  после усреднения.
- «Скачать CSV» — все значения тегов с графиков за период, для Excel.

**Скрипты** (новая страница)

- Короткие скрипты на языке, похожем на Python, по уже скопированным данным: пики
  (`peaks`), значения выше или ниже порога (`above`, `below`, `between`, `where`), время над
  порогом (`duration`), пересечения (`crossings`), сглаживание, скорость изменения, сдвиг,
  разности тегов, корреляция (`corr`) и линейная модель (`fit`).
- Примеры, вставка имени тега поиском, справка по функциям на странице, ошибки с номером
  строки.
- Сохранённый скрипт можно положить на любой график рядом с тегами; пики рисуются кружками на
  линии своего тега.
- Скрипт выполняется в «песочнице» и ничего не меняет ни в историке, ни в базе.

**Прочее**

- Новый спокойный светлый вид страниц.
- Номер версии — внизу страниц и в окне `start.bat`.
- Комплект без Docker обновляется архивом-обновлением (`build-offline.ps1 -Update`, около
  150 КБ) — см. README, раздел «Обновление комплекта».

Новых библиотек версия не требует. База обновляется сама при первом запуске: добавляется таблица
сохранённых скриптов, скопированные данные не меняются.
